# Установка PiRate — инструкция для начинающих

PiRate работает на **совместимых Raspberry Pi с Raspberry Pi OS Lite (64-bit)**. Для установки обычно нужен компьютер, Raspberry Pi с microSD, доступ в домашнюю сеть и интернет. Совместимость с каждой моделью/каждым Wi-Fi-адаптером пока не проверена.

> **Важно:** на Raspberry Pi установщик запускается **одной командой**: `sudo ./install-pi.sh`. Все необходимые системные пакеты он устанавливает автоматически, если есть интернет. Но сначала нужно перенести архив с компьютера на Raspberry Pi.

## 1. Подготовьте Raspberry Pi

1. Запишите **Raspberry Pi OS Lite (64-bit)** на microSD через Raspberry Pi Imager.
2. В настройках Imager **создайте пользователя и пароль** (например, `pi`) и **включите SSH**. В современных Raspberry Pi OS пользователь `pi` не создаётся автоматически, если вы его не указали.
3. Подключите Raspberry Pi к домашнему роутеру по **Ethernet**, вставьте microSD и включите устройство. Компьютер и Raspberry Pi должны находиться в одной локальной сети.
4. Дождитесь загрузки ОС.

## 2. Найдите локальный IP-адрес Raspberry Pi

**Самый надёжный способ — через домашний роутер.** Откройте его страницу управления (адрес часто указан на наклейке роутера), перейдите в список подключённых устройств / DHCP-клиентов и найдите имя Raspberry Pi (оно зависит от того, что задано в Imager). Например, `192.168.1.50` — **только пример**, у вас IP будет другим.

**Если Raspberry Pi подключена к монитору и клавиатуре:** войдите в её терминал и выполните:

```bash
hostname -I
```

Выберите локальный IPv4-адрес, соответствующий домашней сети.

**Если знаете имя устройства:** можно попробовать на Windows PowerShell:

```powershell
ping -4 raspberrypi.local
```

Замените `raspberrypi` на hostname, заданный в Imager (например, `pi.local`). Поиск `.local` работает не во всех сетях, поэтому при неудаче смотрите список устройств на роутере.

Проверьте SSH **на компьютере** (замените имя пользователя и IP на свои):

```bash
ssh pi@192.168.1.50
```

При первом входе подтвердите ключ сервера (`yes`), введите **пароль пользователя Raspberry Pi**, заданный в Imager. Если вход не получается, сначала проверьте правильность IP, имени пользователя и включение SSH.

## 3. Скачайте и перенесите файлы на Raspberry Pi

На **компьютере** скачайте из GitHub Releases два файла (после публикации релиза):

- `pirate-0.5.9-beta.1.tar.gz` — установочный архив.
- `pirate-0.5.9-beta.1.tar.gz.sha256` — файл проверки целостности.

### Windows — самый простой вариант с перетаскиванием мышью

1. Откройте **WinSCP** (SFTP-клиент). Выберите протокол **SFTP**.
2. Укажите **Host name**: IP Raspberry Pi (например, `192.168.1.50`), **Port**: `22`, **User name**: созданный пользователь (`pi`) и его SSH-пароль.
3. Подключитесь. В правой панели откройте домашнюю папку `/home/pi` (или `/home/ВАШ_ПОЛЬЗОВАТЕЛЬ`).
4. Перетащите в неё из папки «Загрузки» Windows **оба скачанных файла**.

WinSCP: https://winscp.net/ (устанавливается на Windows отдельно).

### Windows — без дополнительных программ (PowerShell)

Если не хотите использовать WinSCP, выполните **на Windows в PowerShell** (заменив IP и имя пользователя):

```powershell
scp "$env:USERPROFILE\Downloads\pirate-0.5.9-beta.1.tar.gz" "$env:USERPROFILE\Downloads\pirate-0.5.9-beta.1.tar.gz.sha256" pi@192.168.1.50:/home/pi/
```

`scp` попросит пароль Raspberry Pi. В Windows CMD вместо `$env:USERPROFILE` используется `%USERPROFILE%`.

### macOS или Linux — Терминал

На **компьютере** выполните:

```bash
scp ~/Downloads/pirate-0.5.9-beta.1.tar.gz ~/Downloads/pirate-0.5.9-beta.1.tar.gz.sha256 pi@192.168.1.50:/home/pi/
```

Если имя пользователя не `pi`, замените его и домашнюю директорию `/home/pi/` на свои значения.

## 4. Установите PiRate на Raspberry Pi

Подключитесь по SSH с компьютера (или используйте локальный терминал Raspberry Pi):

```bash
ssh pi@192.168.1.50
```

Дальше команды выполняются **уже на Raspberry Pi**:

```bash
cd ~
sha256sum -c pirate-0.5.9-beta.1.tar.gz.sha256
tar -xzf pirate-0.5.9-beta.1.tar.gz
cd pirate-0.5.9-beta.1
sudo ./install-pi.sh
```

Проверка `sha256sum` должна показать `OK`. Если архива или файла `.sha256` нет, сначала проверьте перенос из шага 3. Если распакованный каталог называется иначе, проверьте его имя командой `ls`.

Установщик автоматически проверит/поставит зависимости, выберет безопасную конфигурацию и подготовит WebUI. Если несколько сетевых адаптеров подходят одинаково или один уже занят важным подключением, установщик может остановиться с объяснением — он **не должен разрывать SSH или WAN наугад**.

## 5. Откройте WebUI на компьютере

На Raspberry Pi с установленным браузером адрес: **http://127.0.0.1:8765**.

На своём **компьютере** откройте **второе** окно PowerShell/Терминала и выполните:

```bash
ssh -N -L 127.0.0.1:8765:127.0.0.1:8765 pi@192.168.1.50
```

**Оставьте это окно открытым**. Теперь в браузере компьютера откройте **http://127.0.0.1:8765**.

Логин WebUI: `admin`. Если требуется установить или сменить пароль, на Raspberry Pi выполните `sudo pirate passwd`.

После входа настройте точку доступа и VPN/Proxy, нажмите **Apply** и затем **Confirm** при успешной проверке. До подтверждения клиентская сеть может оставаться отключённой — это штатный механизм безопасности.

## Если что-то пошло не так

- **Не знаете IP?** Снова посмотрите DHCP-клиентов домашнего роутера или выполните `hostname -I` на Raspberry Pi.
- **`Permission denied` при SSH/SCP?** Проверьте имя пользователя, пароль, IP и что SSH включён в Raspberry Pi Imager.
- **Ошибка при переносе файла?** Скопируйте файлы в домашнюю папку пользователя, а не в защищённые системные каталоги.
- **WebUI не открывается?** Проверьте, что SSH-туннель остался запущен; не вводите IP Raspberry Pi вместо `127.0.0.1` в адресе WebUI.
- **Нужны логи?** На Raspberry Pi выполните `pirate status`; подробные сообщения — во вкладке **Логи** WebUI. Не публикуйте пароли, приватные ключи и полные VPN-конфиги.
