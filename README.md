# PiRate — Raspberry Pi VPN Router & Wi-Fi Hotspot

**PiRate** is an open-source Wi-Fi hotspot and VPN/proxy router for compatible **Raspberry Pi devices running Raspberry Pi OS 64-bit**. Control WireGuard, OpenVPN, SOCKS5, HTTP proxy and direct internet access through a local WebUI.

**PiRate** превращает совместимую **Raspberry Pi под управлением Raspberry Pi OS (64-bit)** в Wi-Fi-точку доступа с удобным управлением через браузер. Доступные режимы: **Direct, WireGuard, OpenVPN, SOCKS5 и HTTP Proxy**.

> **v0.5.9-beta.1 — первый публичный бета-релиз (Pre-release).** Не является стабильной версией. Физически ранее проверялась Raspberry Pi 4; работа на всех моделях и Wi-Fi-адаптерах не гарантируется.

## Возможности

- **Wi-Fi-точка доступа:** настройка AP на подходящем адаптере Raspberry Pi.
- **VPN и прокси:** WireGuard, OpenVPN, SOCKS5, HTTP Proxy или прямой выход через WAN.
- **WebUI 2.0:** профили подключений и Wi-Fi, логи, диагностика и управление из браузера.
- **Safe Apply:** применение с подтверждением, автоматическим откатом и fail-closed.
- **Установка одной командой:** установщик определяет стандартную конфигурацию и добавляет недостающие пакеты.

**PPTP не входит в этот релиз.**

## Требования

- Совместимая Raspberry Pi с **Raspberry Pi OS Lite (64-bit, ARM64)**; текущий целевой дистрибутив — Debian Trixie.
- Ethernet или другой отдельный WAN-канал, доступ по SSH и `sudo`.
- Свободный Wi-Fi-адаптер, поддерживающий режим AP и не используемый для WAN/SSH.
- Интернет для автоматической установки недостающих пакетов через `apt`.

**Совместимость:** проект рассчитан на совместимые модели Raspberry Pi с 64-битной ОС, но **не все поколения и Wi-Fi-чипсеты проверены физически**. При двух подходящих AP-адаптерах установщик может попросить явно выбрать один вместо рискованного автоматического переключения.

## Установка и обновление

**[Пошаговая инструкция для начинающих: найти IP Raspberry Pi, перенести файлы с ПК и установить PiRate](INSTALL.md).** В ней есть вариант Windows с перетаскиванием файлов через WinSCP, команды PowerShell и инструкции для Linux/macOS.

Коротко: скачайте `pirate-0.5.9-beta.1.tar.gz` и `.sha256` из **GitHub Releases**, **перенесите оба файла с компьютера на Raspberry Pi** по SFTP/SCP и выполните на Raspberry Pi:

```bash
cd ~
sha256sum -c pirate-0.5.9-beta.1.tar.gz.sha256
tar -xzf pirate-0.5.9-beta.1.tar.gz
cd pirate-0.5.9-beta.1
sudo ./install-pi.sh
```

При обновлении используется та же команда. Установщик проверяет зависимости и сохраняет существующие настройки. Он не должен отключать используемый для SSH/WAN интерфейс.


## Как открыть WebUI

После установки следуйте короткой инструкции, напечатанной установщиком. На Raspberry Pi с браузером откройте `http://127.0.0.1:8765`.

На своём компьютере (Windows PowerShell, macOS или Linux) создайте SSH-туннель, заменив пользователя и адрес на свои:

```bash
ssh -N -L 127.0.0.1:8765:127.0.0.1:8765 USER@PI_ADDRESS
```

Не закрывайте окно с командой и откройте в браузере **http://127.0.0.1:8765**. Логин WebUI по умолчанию: `admin`. Пароль задаётся или меняется на Raspberry Pi командой `sudo pirate passwd`.

## Первый запуск

1. Настройте Wi-Fi AP (имя сети и пароль) в WebUI.
2. Добавьте или импортируйте профиль WireGuard/OpenVPN либо настройте прокси.
3. Примените изменения и **подтвердите** их, если подключение работает.

Сохранение профиля само по себе его не активирует. Новая установка не открывает AP и клиентский интернет до применения и подтверждения. Ошибки можно найти во вкладке **Логи** и скачать в виде очищенного отчёта.

**Проверка подключений:** не считайте доступность DNS или TCP-порта подтверждением работающего VPN. В этом выпуске полная изолированная проверка WireGuard/OpenVPN пока не реализована: подробная причина результата отображается в журнале. Проверка прокси подтверждает реальный HTTPS-трафик через прокси и внешний IPv4.

## FAQ

**Работает ли PiRate на любой Raspberry Pi?** На совместимых моделях с Raspberry Pi OS 64-bit и подходящим Wi-Fi AP-адаптером. Поддержка всех моделей пока не подтверждена тестами.

**Можно ли сделать WireGuard/OpenVPN Wi-Fi роутер на Raspberry Pi?** Да: PiRate позволяет настроить AP и применить профиль VPN через WebUI с подтверждением изменений.

**Нужно ли устанавливать VPN-пакеты вручную?** Обычно нет — установщик добавляет отсутствующие зависимости при наличии интернета.

**Почему WebUI не открывается по IP Raspberry Pi?** По умолчанию он слушает локальный адрес `127.0.0.1` для безопасного доступа через SSH-туннель.
