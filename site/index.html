OPEN SOURCE · RASPBERRY PI OS 64-BIT

Your Raspberry Pi.
Your VPN Router.

A browser-managed Wi-Fi hotspot for compatible Raspberry Pi devices. Switch between WireGuard, OpenVPN, SOCKS5, HTTP proxy and Direct modes using a local WebUI.

One-command setup

Install missing Debian packages automatically on standard setups.

VPN & Proxy

Manage profiles without editing configuration files by hand.

Local-first controls

Safe Apply/Confirm/Rollback, Linux-style logs and diagnostics.

Install from the release archive

tar -xzf pirate-0.5.9-beta.1.tar.gz
cd pirate-0.5.9-beta.1
sudo ./install-pi.sh

v0.5.9-beta.1 is a planned public beta. The archive and GitHub release are not published. Raspberry Pi 4 has previous hands-on testing; all hardware variants are not verified.
