# Changelog / История изменений

## v0.5.9-beta.1 — First Public Beta (proposed)

Based on the reviewed `0.5.9-rc4` release candidate; runtime changes must be verified during final packaging.

- Public modes: Direct, WireGuard, OpenVPN, SOCKS5 and HTTP Proxy.
- Local WebUI 2.0 and Linux-style logs / diagnostic export.
- One-command installer with safe AP/WAN detection and automatic dependencies.
- Safe Apply / Confirm / Rollback, fail-closed and backup retained.
- PPTP excluded from public runtime.
- MIT license adopted; bug reports preferably via PiRate Telegram.
- Published identity switched from internal RC to public beta version.

**Status:** Public beta candidate. The final rebuilt beta.1 package is not yet independently tested on physical hardware.

## 0.5.9-rc4 — internal approval candidate

Reviewed source snapshot and release preparation base. Not a stable public release.
