# Настройки PiRate

Все обычные настройки находятся в WebUI.

- **Direct:** интернет через WAN без VPN/proxy.
- **WireGuard:** импорт конфигурации или ключи, адрес интерфейса и endpoint.
- **OpenVPN:** импорт `.ovpn`; логин/пароль, если требуется сервером.
- **SOCKS5 / HTTP Proxy:** сервер, порт и учётные данные при необходимости.
- **Wi-Fi:** имя сети, пароль и доступные параметры AP-адаптера.

Сохранить, изменить или дублировать профиль можно без активации. Для переключения
используйте подключение и подтвердите результат в отведённое интерфейсом время.
При отказе/тайм-ауте Safe Apply возвращает прежние настройки. Disconnect не
является командой переключения на Direct.

Туннели используют существующую политику IPv4. В этом кандидате не добавляется
новая DNS Auto/ISP-база. DNS выбирается существующими средствами панели.

Кнопка «Проверить» не меняет маршруты, DNS, firewall или активный профиль.
Проверка proxy обращается через него к `https://api.ipify.org/`, проверяет TLS,
передачу данных и корректный внешний IPv4. Это точечная проверка, а не гарантия
работы каждого сайта. Совпадающий активный аккаунт не проверяется параллельно.

Изолированная проверка VPN в этом кандидате недоступна. «Не работает» также
используется, когда безопасная полная проверка невозможна или отменена: точная
причина записана в Логи. Доступный TCP-порт никогда не даёт «Работает».
